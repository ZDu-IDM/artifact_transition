IDM package index

Python packages migrated from Artifactory (packages.idmod.org) to GitHub Releases, served here as a PEP 503 simple index.

Install

pip install --index-url https://zdu-idm.github.io/artifact_transition/simple/ emodpy

Or add it as an extra index alongside PyPI:

pip install --extra-index-url https://zdu-idm.github.io/artifact_transition/simple/ emodpy

Browse the full list at /simple/.
